## Storage policy

Future generated illustration assets for this project should be copied from the tool's generated-image directory into `illustration-style/` before the task is considered complete. Selected assets receive descriptive filenames; rejected or intermediate generations go into a local `drafts/` directory rather than being left outside the repository.
